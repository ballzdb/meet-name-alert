# Privacy Policy: Meet Name Alert

Meet Name Alert runs entirely inside your browser.

- It reads the live caption text on `meet.google.com` only to check whether it contains the names you entered.
- It does **not** record audio or video, and does **not** store, collect, or transmit caption text or any personal data.
- The only data saved is the list of names you type in the popup, stored via `chrome.storage.sync` in your own browser profile.
- No analytics, no third-party services, no servers.

## Permissions used

- `storage`: to save your list of names.
- `notifications`: to show a desktop notification when your name is detected.
- Access to `meet.google.com`: to read the captions on the page.
